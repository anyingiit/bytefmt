# Security Policy

## Supported Versions

`bytefmt` is released continuously. Only the latest release receives security
fixes, so please upgrade to the most recent tag before reporting an issue.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

This repository follows the Cloud Foundry Foundation (CFF)
[security policy](https://github.com/cloudfoundry/.github/blob/master/SECURITY.md).
The CFF Security Team is the single point of contact for reporting security
vulnerabilities in open source Cloud Foundry codebases and coordinates the
investigation of any reports.

- E-mail: **security@cloudfoundry.org**
- Encrypted e-mail: fetch the public key from a key server such as
  keys.openpgp.org. Fingerprint:
  `3FC8 9AF3 940B E270 CF25  E122 9965 0006 EF9D C642`
- If GitHub [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  is enabled for this repository, you can also use the **Report a
  vulnerability** button on the **Security** tab.

Only use the addresses above for undisclosed security vulnerabilities. Regular
bug reports belong in the GitHub issue tracker.

More information: <https://www.cloudfoundry.org/security/>
